# 🚀 Roberto Garrahan — Portfolio v2

This is my personal portfolio built to showcase my professional experience, projects, and technical skills as a **Software Engineer**.

The project was designed with a focus on performance, scalability, clean UI/UX, and modern web architecture. It highlights real-world systems, fullstack development experience, and software engineering practices.

The portfolio is fully responsive, optimized for performance, and supports multiple languages (English and Portuguese).

---

# 🧠 About the Project

This portfolio represents the second version (v2) of my personal website, rebuilt from scratch using modern technologies and best practices.

The goal of this project is to provide a professional and technical overview of my work as a developer, including:

* Professional experience
* Featured projects
* Technical skills
* Certifications and education
* Achievements and hackathons
* Contact and social links

It was designed not just as a personal website, but as a **production-level frontend project**, focusing on clean architecture, animations, performance, and scalability.

---

# 🖥️ Running Locally

## Requirements

* Node.js 18+
* npm or yarn

## Clone repository

```bash
git clone https://github.com/RobertoGarrahan/portfolio-v2.git
```

## Install dependencies

```bash
npm install
```

## Run project

```bash
npm run dev
```

## Open in browser

```
http://localhost:3000
```
